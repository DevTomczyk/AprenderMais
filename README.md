## Descrição

Aplicação web desenvolvida em Angular para apresentar uma plataforma fictícia de cursos. A pessoa usuária pode visualizar informações como nível, carga horária, certificado, vagas e status da matrícula.

## Funcionalidades

- Catálogo de cursos exibido dinamicamente a partir do TypeScript;
- Visualização dos detalhes de cada curso;
- Matrícula e cancelamento fictícios, com atualização das vagas;
- Marcação de cursos favoritos;
- Login/logout fictício, que altera a mensagem de boas-vindas;
- Mensagens condicionais para vagas disponíveis, turma esgotada e matrícula realizada;
- Interface responsiva para celular, tablet e desktop.

## Tecnologias

- Angular 19
- TypeScript
- HTML5 semântico
- CSS3 (Flexbox e Grid)

## Componentes criados

- `HeaderComponent`: cabeçalho, navegação e login fictício;
- `CourseCatalogComponent`: catálogo de cursos;
- `CourseCardComponent`: cartão de cada curso;
- `CourseDetailsComponent`: detalhes do curso selecionado;
- `FooterComponent`: rodapé da aplicação.

## Como executar

1. Abra a pasta do projeto no VS Code.
2. No terminal, execute `npm install`.
3. Execute `ng serve` ou `npm start`.
4. Acesse `http://localhost:4200` no navegador.
